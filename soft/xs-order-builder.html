Generated files

Safety check required: Before production use, open a generated file in xTool Studio, confirm the displayed text and Black device image, confirm the text is centred, verify the device bitmap is ignored, verify blue-laser fill engraving remains power 100 / speed 80 / density 300, frame the job, and engrave a sacrificial test device.
Operator steps
  1. Add an order or import the day's CSV.
  2. Resolve every red validation error. Invalid rows are never generated.
  3. Optionally choose a local output folder, then select Generate valid .xs files.
  4. Open the file named for the OrderID in xTool Studio.
  5. Check text, colour image, centring, ignored bitmap, and laser settings.
  6. Place the matching Black device in the approved jig, frame, then engrave according to the approved LSP safety procedure.
